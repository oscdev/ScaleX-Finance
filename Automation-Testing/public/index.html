How to use this page

Test Personal Loan and Business Loan pipelines: look up rules offline, replay a lead’s disk logs, or run a full end-to-end Live Run against Strapi.

Offline No Strapi · no DB writes

  • Rules & Scoring Reference — formulas, field sources, eligibility & scoring rules.
  • Journey Demo — load a lead’s logs from logs/ (submission → bureau → eligibility → scoring).

Online Needs Strapi · writes DB

  • Live Run — creates a real [SUITE-TEST] lead, uploads docs, waits for bureau, runs AI Match, writes an HTML report.
  • Requires Strapi (npm run dev in the project root). Check the status pill above.
  1. Live Run: pick product → confirm → Start (online only).
  2. Rules & Scoring Reference: pick product → open Lead / Bureau / Eligibility / Scoring docs (offline).
  3. Journey Demo: pick loan type + stage → optional Lead ID → Load (offline). Wrong product for an ID shows which product it belongs to.

Live Run — create lead + full pipeline

Writes DB

Creates a real lead and loan application tagged [SUITE-TEST], uploads documents from Automation-Testing/documents/{product}/, waits for bureau extraction, then runs AI Match. Status updates here when the run finishes (async — no long proxy wait). Opens a detailed HTML report.

  • Product — Personal Loan or Business Loan.
  • Confirm checkbox — required; acknowledges DB writes.
  • Start Live Run — runs in the background (bureau may take several minutes).

1. Rules & Scoring Reference

Offline

Offline catalog of lead fields, bureau inputs, eligibility rules, and scoring criteria (formulas and data sources). Pick a product, then open a section. Click the same button again to hide results.

    2. Journey Demo

    Offline

    Reads existing code-level logs under logs/ for a lead — no Strapi calls. Leave Lead ID empty to load the latest lead for the selected loan type. Eligibility and Scoring use a lender dropdown and step tables (same layout as the Legacy PL report).

    • Loan Type — Personal Loan or Business Loan log folders.
    • Stages — All, or one of: Lead Submission, Bureau, Eligibility, Scoring.
    • Lead ID — optional; searches that lead’s logs only.

    Tips

    • Strapi is required only for Live Run — check the status pill. Rules Reference and Journey Demo work offline.
    • Journey Demo Lead ID must match the selected Loan Type; otherwise the error names the correct product.
    • Hard-refresh (Ctrl+Shift+R) after suite updates so app.js / CSS reload.
    • Live Run HTML reports land under Automation-Testing/reports/runs/.
    • Set SUITE_ADVISOR_REFERRAL_ID in Automation-Testing/.env if lead create requires an advisor referral.
